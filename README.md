# 便便日记

一个手机优先、无需账号的每日如厕记录网页。支持快捷记录、7/30 天趋势、安装到手机桌面和离线使用。数据使用浏览器 `localStorage` 保存在当前设备，不会上传到服务器。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库。
2. 把本文件夹中的全部文件上传到仓库根目录。
3. 上传到 `main` 分支后，仓库内置的 GitHub Actions 会自动发布网站。
4. 在仓库的 **Actions** 页面等待 “Deploy GitHub Pages” 完成。
5. 打开 `https://你的用户名.github.io/仓库名/`；网页右上角的数据设置中可以选择“添加到手机桌面”。

> 换手机或清理浏览器数据前，请先在网页右上角导出 JSON 备份。
